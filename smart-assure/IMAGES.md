# Images to add

Drop every file into **`public/images/`** using the **exact file name** below.
The folder ships empty. Any file that isn't there yet shows a small labelled
placeholder instead, so the app always looks finished.

Ratios matter, pixel sizes don't — each image is cropped to fill its slot
(`object-fit: cover`), so a photo at the right ratio will never look squashed.
Use JPG for photographs. Aim for roughly 1600px on the long edge; anything
larger just slows the page down.

**24 files in total.** The four `problem-*.jpg` tiles and the three
`triage-*.jpg` photos are the ones a jury will look at hardest, so pick those
first if you're short on time.

A note on sourcing: free stock sites (Unsplash, Pexels) cover the terraces,
portraits and tools well. Search terms that work: *water damage ceiling*,
*monsoon terrace india*, *construction worker india portrait*, *waterproof
coating roller*, *moisture meter wall*.
